# Playboi Carti — Pixel-Matched Webpage

Open `index.html` in a browser.

## Important
- No PNG/JPG/WebP assets are used by the webpage.
- Every image/logo/emblem area is represented by a CSS asset placeholder.
- The page uses a 1536 × 1024 design canvas (3:2), matching the supplied reference dimensions.
- The layout scales proportionally on smaller/larger screens.
- The countdown starts at the exact visual value from the reference: 11:05:42:19.
- Google Fonts are requested for the closest available display typography; fallbacks are included if the fonts are unavailable.

To replace an asset later, replace the corresponding placeholder element while keeping its dimensions/position.
